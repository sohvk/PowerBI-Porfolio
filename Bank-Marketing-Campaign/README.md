## Project 1: Bank Marketing Campaign Performance

**Goal:** Analyze how a bank's marketing campaign performed and which customer segments responded best, so teams can see where to focus outreach.

**Data:** Bank customer data dataset from [Kaggle](https://www.kaggle.com/kidoen/bank-customers-data).

**Tools:** Power BI, Excel, Figma, DAX, Power Query

**Highlights:**
- **Landing page:** A designed entry page in Figma that guides users into the report pages and makes navigation intuitive. Also, user can see the last refresh time and changes made to the report.
- **Hidden filter panel:** A slide-out filter menu that keeps the canvas clean while still allowing deep, interactive slicing of the data.
- **Data preparation:** Cleaning and transforming the raw data in Power Query, with campaign KPIs calculated in DAX.
- **Pages:** Overview → Customer Segments → AI Insights
